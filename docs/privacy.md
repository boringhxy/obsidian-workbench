# 隐私与发布边界

仓库只保存插件代码、通用安装与迁移逻辑、设计说明、主题参数和合成测试示例。

不应提交：实际Obsidian知识库、插件data.json、个人待办、提醒事项数据库、Remindian的config.json/profiles.json/sync_state/sync_log、系统安全书签、安装备份、截图中的账号或财务信息、令牌与密钥。

`.gitignore`是防误提交辅助；发布前仍需检查已跟踪文件和首次提交。测试与构建不能依赖真实用户目录，发布包使用白名单打包三份插件文件，不打包运行时数据。

完整私人部署日志另行保存。仓库CHANGELOG是移除电脑路径、个人任务与运行快照后的开发版本记录；没有把历史版本伪造为逐次Git提交。
